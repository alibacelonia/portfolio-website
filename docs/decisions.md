# Decisions

| ID   | Decision                                                                                                                                              | Reason                                                                                                                                                                                |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-01 | Next.js 16.4, React 19.3, Tailwind 4.3, Motion 14.6 (`motion/react`).                                                                                 | Current stable releases on 2026-10-23.                                                                                                                                                |
| D-02 | TypeScript 5.9 and ESLint 9, not TypeScript 7 / ESLint 10.                                                                                            | TS 7 (native port) and ESLint 10 are newer than the Next 16 lint and type tooling was built against; 5.9/9 are fully supported. Revisit when `eslint-config-next` declares support.   |
| D-03 | No project category filter.                                                                                                                           | Four projects fit on one screen; a filter would add clicks without utility. Categories are shown as tags instead.                                                                     |
| D-04 | Section entrances use CSS + `IntersectionObserver` gated on `html.js`, not Motion `initial` props.                                                    | Motion's SSR `initial` state would ship `opacity:0` in static HTML and hide content when JS is disabled.                                                                              |
| D-05 | Dock on `md+`; header disclosure menu below `md`. Never both.                                                                                         | Satisfies “single primary navigation” while fitting 320 px screens without covering content.                                                                                          |
| D-06 | Pipeline renders a neutral idle state in HTML, runs one sequential pass when first visible, then rests on “passed”. A “Run again” control replays it. | No looping animation; meaningful without JS; reduced motion shows the final state immediately.                                                                                        |
| D-07 | Formspree via `fetch` + JSON, honeypot field `_gotcha`, and a minimum fill time (3 s) check.                                                          | Static-compatible, no secrets; Formspree discards `_gotcha` submissions server-side.                                                                                                  |
| D-08 | Unconfigured form → `mailto:` fallback with explicit wording.                                                                                         | Never shows a false success.                                                                                                                                                          |
| D-09 | Cloud Practitioner credential URL taken from the resume's embedded link and verified on Credly.                                                       | Brief asked to keep it configurable until verified; it is now verified, still editable in data.                                                                                       |
| D-10 | S3 SSE-S3 (AES256) rather than SSE-KMS.                                                                                                               | Public website assets; SSE-KMS adds cost and requires KMS permissions for CloudFront without a security benefit here.                                                                 |
| D-11 | S3 versioning on, noncurrent versions expire after 30 days.                                                                                           | Enables rollback of a bad deploy at negligible cost.                                                                                                                                  |
| D-12 | `trailingSlash: true` + CloudFront Function that maps `/path/` → `/path/index.html`.                                                                  | Correct directory URLs for any future pages without exposing an S3 website endpoint.                                                                                                  |
| D-13 | Default `PriceClass_200`.                                                                                                                             | Includes Asia edge locations (owner is in the Philippines) at a lower cost than `PriceClass_All`.                                                                                     |
| D-14 | ACM via DNS validation; Route 53 records only when a zone ID is supplied.                                                                             | `alibacelonia.dev` DNS is on Cloudflare; Route 53 ownership is not assumed.                                                                                                           |
| D-15 | Old `_next/static` files are not deleted on deploy.                                                                                                   | Prevents broken chunks for visitors holding an older HTML document; files are tiny and hashed.                                                                                        |
| D-16 | Resume PDF served from `public/documents/`; flagged because it contains a street address and phone number.                                            | Brief requires a resume download; publication of contact details is the owner's call.                                                                                                 |
| D-17 | No installed `frontend-design` or Motion skill exists; the `ui-ux-pro-max` plugin is scoped to another project. Standards applied manually.           | Brief: do not claim or install skills without checking.                                                                                                                               |
| D-18 | Dock indicator and theme icon use CSS transitions; Motion's mobile-menu panel is lazy-loaded; `LazyMotion` uses `domAnimation`, not `domMax`.         | Motion layout animations added ~45 KB gzipped of initial JS for one indicator. Initial JS fell from 237 KB to 199 KB gzipped (≈160 KB is the Next.js/React runtime).                  |
| D-19 | Reduced-motion preference read through `useSyncExternalStore` with a `false` server snapshot.                                                         | Motion's `useReducedMotion` returns the real value on the first client render, causing a hydration mismatch (React #418) that discarded the theme attributes. Covered by an E2E test. |
| D-20 | The Open Graph image is exported extensionless (`/opengraph-image`); `scripts/deploy.sh` uploads it with `Content-Type: image/png`.                   | Next.js metadata-route naming; S3 cannot infer a type without an extension.                                                                                                           |
